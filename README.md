# ShonieStyle — простая инструкция по редактированию сайта

Этот сайт можно менять **прямо через GitHub**, без сложной настройки.
В большинстве случаев вам нужны только файлы в папке `_data/`.

---

## 1. Коротко: что где менять

| Что хотите изменить | Где менять |
| --- | --- |
| Текст на главной, кнопки, верхнюю плашку, footer | `_data/en/site.yml` и `_data/de/site.yml` |
| Вопросы и ответы FAQ | `_data/en/faq.yml` и `_data/de/faq.yml` |
| Карточки категорий | `_data/en/categories.yml` и `_data/de/categories.yml` |
| Порядок блоков на главной | `_layouts/home.html` |
| Структуру страницы FAQ | `_layouts/faq.html` |
| Юридические страницы | `impressum.md`, `datenschutz.md`, `agb.md`, `widerrufsbelehrung.md` |
| Картинки | `assets/images/` |

> Английская версия сайта открывается на `/`
> Немецкая версия — на `/de/`

---

## 2. Главное правило

Запомнить нужно только одно:

- **тексты** лежат в `_data/en/*` и `_data/de/*`
- **структура страниц** лежит в `_layouts/` и `_includes/`
- одинаковую HTML/Liquid-разметку между языками **не дублируем**


---

## 3. Самые частые задачи с примерами

### Пример 1 — поменять текст кнопки на главной
Откройте:
- `_data/en/site.yml`
- `_data/de/site.yml`

И найдите блок `hero:`.

Пример:

```yml
hero:
  primary_label: "Visit Etsy shop"
  secondary_label: "Read the FAQ"
```

Для немецкой версии:

```yml
hero:
  primary_label: "Zum Etsy-Shop"
  secondary_label: "FAQ lesen"
```

---

### Пример 2 — добавить новый вопрос в FAQ
Откройте:
- `_data/en/faq.yml`
- `_data/de/faq.yml`

Добавьте новый элемент в список.

Пример для английской версии:

```yml
- question: "Do I get a PDF after purchase?"
  answer: "Yes, the sewing pattern is delivered as a digital download."
```

Пример для немецкой версии:

```yml
- question: "Bekomme ich nach dem Kauf ein PDF?"
  answer: "Ja, das Schnittmuster wird als digitaler Download bereitgestellt."
```

---

### Пример 3 — поменять порядок блоков на главной
Откройте файл `_layouts/home.html`.

Сейчас структура выглядит так:

```liquid
{% include hero.html %}
{% include category-grid.html %}
{% include about-brand.html %}
{% include faq-preview.html %}
```

Если хотите, например, поставить FAQ выше блока `about-brand`, просто поменяйте строки местами.

---

### Пример 4 — поменять структуру FAQ-страницы
Откройте `_layouts/faq.html`.

Этот файл отвечает за:
- заголовок страницы FAQ
- секцию с вопросами
- блок `Offer of the week` / `Angebot der Woche`
- контактный блок

А сами тексты к этим секциям лежат в:
- `_data/en/site.yml` → `faq_page`
- `_data/de/site.yml` → `faq_page`

---

### Пример 5 — заменить картинку
1. Загрузите новую картинку в `assets/images/`
2. Откройте нужный `.yml` файл
3. Найдите строку `image:`
4. Подставьте путь к новой картинке

Пример:

```yml
image: "/assets/images/category-women.jpg"
```

---

## 4. Какие файлы обычно **не нужно** трогать

Обычно не требуется редактировать:
- `index.html`
- `de/index.html`
- `faq.md`
- `de/faq.md`

Эти файлы теперь служат в основном как **маршруты и языковые настройки**.

Если вы меняете только тексты, лучше **не трогать**:
- `_layouts/`
- `_includes/`
- `assets/css/site.css`
- `_config.yml`
- `Gemfile`

---

## 5. Как редактировать сайт через GitHub

1. Откройте нужный файл в репозитории.
2. Нажмите значок карандаша **Edit this file**.
3. Внесите изменения.
4. Нажмите **Commit changes**.
5. Подождите 1–2 минуты, пока сайт обновится.

---

## 6. Быстрая проверка после изменений

После любой правки проверьте:

- [ ] если меняли текст, обновлены обе языковые версии (`en` и `de`)
- [ ] если меняли FAQ, проверены `/faq/` и `/de/faq/`
- [ ] если меняли главную, проверены `/` и `/de/`
- [ ] если меняли Etsy-ссылку, она обновлена в нужном `site.yml`
- [ ] если меняли структуру, правка сделана в `_layouts/` / `_includes/`, а не копированием HTML в два языка

---

## 7. Если что-то сломалось

Чаще всего проблема в одном из этих мест:
- случайно удалили отступы в `.yml`
- забыли кавычки
- удалили двоеточие после названия поля

Что делать:
1. откройте последний изменённый файл;
2. проверьте отступы и знаки `:`;
3. при необходимости вернитесь к предыдущему коммиту.

---

## 8. Важно помнить

- Страницы `Impressum`, `Datenschutzerklärung`, `AGB`, `Widerrufsbelehrung` **специально оставлены на немецком языке**.
- Перед публикацией убедитесь, что фотографии, тексты и юридические данные у вас свои и корректные.
- Юридические тексты в проекте — это **шаблоны**, а не юридическая консультация.
