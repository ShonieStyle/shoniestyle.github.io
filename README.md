# ShonieStyle — как редактировать сайт

Этот сайт сделан так, чтобы его можно было менять **прямо через GitHub в браузере**, без специальных знаний.

---

## Самое важное

Сайт теперь **двуязычный**:
- английская версия — основная, открывается по адресу `/`
- немецкая версия — открывается по адресу `/de/`
- язык можно переключать кнопками `EN / DE` в шапке сайта

Обычному пользователю обычно нужно менять только эти файлы:

- `_data/en/site.yml` — тексты английской главной страницы
- `_data/en/categories.yml` — английские карточки категорий
- `_data/en/faq.yml` — английские вопросы и ответы
- `_data/de/site.yml` — тексты немецкой главной страницы
- `_data/de/categories.yml` — немецкие карточки категорий
- `_data/de/faq.yml` — немецкие вопросы и ответы
- `faq.md` — английская страница FAQ (`/faq/`)
- `de/faq.md` — немецкая страница FAQ (`/de/faq/`)
- `impressum.md` — выходные данные
- `datenschutz.md` — политика конфиденциальности
- `agb.md` — условия использования
- `widerrufsbelehrung.md` — политика возврата / отказа

> Если вы меняете только тексты, **не трогайте** папки `_layouts`, `_includes`, `assets/css` и файл `_config.yml`.

> Важно: страницы `Impressum`, `Datenschutzerklärung`, `AGB`, `Widerrufsbelehrung` **специально оставлены на немецком языке** из-за немецких юридических требований.

## Как изменить текст на сайте — пошагово

### Вариант 1: через GitHub в браузере

1. Откройте репозиторий сайта на GitHub.
2. Найдите нужный файл в списке.
3. Нажмите на него.
4. Нажмите значок карандаша **Edit this file**.
5. Измените текст.
6. Пролистайте вниз.
7. Нажмите **Commit changes...**.
8. Подтвердите сохранение.
9. Подождите 1–2 минуты — GitHub Pages обновит сайт автоматически.

## Что где менять

### 1. Верхняя полоса, кнопки, главный экран, блок о бренде, footer
Файлы:
- `_data/en/site.yml` — английская версия
- `_data/de/site.yml` — немецкая версия

Здесь можно менять:

- заголовок и текст главного экрана;

### 2. Категории товаров
Файлы:
- `_data/en/categories.yml` — английская версия
- `_data/de/categories.yml` — немецкая версия

Здесь можно менять:

Файлы:

## Как заменить или добавить картинки

Картинки лежат в папке:
- `assets/images/`

### Если нужно заменить существующую картинку
1. Откройте папку `assets/images/`.
2. Загрузите туда новый файл.
3. Откройте нужный `.yml` файл.
4. Найдите строку `image:`.
5. Замените имя файла на новое.

Пример:

```yml
image: "/assets/images/category-women.jpg"
```

### Если нужно добавить новую картинку
1. Нажмите **Add file** → **Upload files** в репозитории GitHub.
2. Загрузите файл в папку `assets/images/`.
3. Скопируйте точное имя файла.
4. Вставьте его в нужное место в `.yml` файле.

> Лучше использовать простые имена файлов без пробелов, например: `hero-photo.jpg`, `logo.png`, `kids-collection.jpg`.

## Как поменять логотип сайта

Теперь логотип можно сделать **или текстом, или картинкой** — без правки шаблонов.

За это отвечают:
- `_data/en/site.yml` — для английской версии
- `_data/de/site.yml` — для немецкой версии
- папка `assets/images/`

### Вариант 1: оставить текстовый логотип
В файле `_data/en/site.yml` или `_data/de/site.yml` используется такой блок:

```yml
brand:
  name: "ShonieStyle"
  logo_text: "SS"
  show_name: true
```

Что можно менять:
- `name:` — название бренда рядом с логотипом;
- `logo_text:` — буквы внутри квадрата;
- `show_name:` — показывать ли название рядом (`true` или `false`).

### Вариант 2: поставить логотип-картинку
1. Загрузите файл логотипа в `assets/images/`, например `logo.png` или `logo.svg`.
2. Откройте `_data/de/site.yml`.
3. Укажите путь к файлу:

```yml
brand:
  name: "ShonieStyle"
  logo_text: "SS"
  logo_image: "/assets/images/logo.png"
  logo_image_alt: "ShonieStyle logo"
  show_name: true
```

Что означают поля:
- `logo_image:` — путь к файлу логотипа;
- `logo_image_alt:` — описание картинки;
- `show_name:` — оставить ли текст названия рядом с картинкой.

> Если в самой картинке уже написано название бренда, можно поставить `show_name: false`.

### Как вернуть текстовый логотип обратно
Просто удалите строку `logo_image:` или оставьте пустое значение:

```yml
logo_image: ""
```

## Что нельзя случайно удалять

Пожалуйста, не редактируйте без необходимости:
- `_layouts/`
- `_includes/`
- `assets/css/site.css`
- `_config.yml`
- `Gemfile`

Эти файлы отвечают за внешний вид и работу сайта.

## Если что-то пошло не так

1. Откройте последний измененный файл.
2. Проверьте, не удалились ли случайно кавычки, двоеточия или отступы.
3. Если сайт отображается странно — вернитесь к предыдущему коммиту или попросите разработчика проверить файл.

## Важно для коммерческого использования и лицензий

На текущий момент сайт сделан безопасно для коммерческого лендинга:

- в проекте используются **оригинальные шаблоны и код**;
- все изображения в `assets/images/` сейчас — это **внутренние SVG-заглушки**, а не чужие фото;
- внешние шрифты из Google не используются, чтобы снизить риски по лицензиям и приватности;
- ссылки на `Etsy` — это обычные внешние ссылки.

### Но перед запуском обязательно проверьте:
- что все реальные фотографии у вас **свои** или куплены с коммерческой лицензией;
- что тексты не скопированы с чужого сайта;
- что страницы `Impressum`, `Datenschutzerklärung`, `AGB`, `Widerrufsbelehrung` заполнены вашими реальными данными и проверены юридически.

> Юридические тексты в проекте сейчас являются **заготовками**, а не юридической консультацией.

## Локальный просмотр сайта (для разработчика)

Если сайт нужно открыть локально на компьютере:

```bash
bundle config set path 'vendor/bundle'
bundle install
bundle exec jekyll serve
```

После этого сайт будет доступен по адресу:
- `http://127.0.0.1:4000`
