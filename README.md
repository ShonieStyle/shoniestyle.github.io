# ShonieStyle — как редактировать сайт

Этот сайт сделан так, чтобы его можно было менять **прямо через GitHub в браузере**, без специальных знаний.

---

## Самое важное

Обычному пользователю обычно нужно менять только эти файлы:

- `_data/de/site.yml` — тексты на главной странице
- `_data/de/categories.yml` — карточки категорий
- `_data/de/faq.yml` — вопросы и ответы на странице FAQ
- `faq.md` — текст страницы FAQ
- `impressum.md` — выходные данные
- `datenschutz.md` — политика конфиденциальности
- `agb.md` — условия использования
- `widerrufsbelehrung.md` — политика возврата / отказа

> Если вы меняете только тексты, **не трогайте** папки `_layouts`, `_includes`, `assets/css` и файл `_config.yml`.

---

## Как изменить текст на сайте — пошагово

### Вариант 1: через GitHub в браузере

1. Откройте репозиторий сайта на GitHub.
2. Найдите нужный файл в списке.
3. Нажмите на него.
4. Нажмите значок карандаша **Edit this file**.
5. Измените текст.
6. Пролистайте вниз.
7. Нажмите **Commit changes...**.
8. Подтвердите сохранение.
9. Подождите 1–2 минуты — GitHub Pages обновит сайт автоматически.

## Что где менять

### 1. Верхняя полоса, кнопки, главный экран, блок о бренде, footer
Файл:
- `_data/de/site.yml`

Здесь можно менять:
- текст промокода;
- ссылку `Angebot der Woche`;
- заголовок и текст главного экрана;
- текст на кнопках;
- блок `О бренде`;
- текст в подвале сайта.

### 2. Категории товаров
Файл:
- `_data/de/categories.yml`

Здесь можно менять:
- названия категорий;
- описания;
- ссылки на Etsy;
- картинки категорий.

### 3. Вопросы и ответы
Файл:
- `_data/de/faq.yml`

Каждый вопрос состоит из двух строк:
- `question:` — вопрос
- `answer:` — ответ

### 4. Юридические страницы
Редактируются напрямую:
- `impressum.md`
- `datenschutz.md`
- `agb.md`
- `widerrufsbelehrung.md`

---

## Как заменить картинки

Картинки лежат в папке:
- `assets/images/`

Что сделать:
1. загрузить новую картинку в эту папку;
2. открыть нужный `.yml` файл;
3. заменить имя файла в строке `image:`.

---

## Что нельзя случайно удалять

Пожалуйста, не редактируйте без необходимости:
- `_layouts/`
- `_includes/`
- `assets/css/site.css`
- `_config.yml`
- `Gemfile`

Эти файлы отвечают за внешний вид и работу сайта.

---

## Если что-то пошло не так

1. Откройте последний измененный файл.
2. Проверьте, не удалились ли случайно кавычки, двоеточия или отступы.
3. Если сайт отображается странно — вернитесь к предыдущему коммиту или попросите разработчика проверить файл.

## Важно для коммерческого использования и лицензий

На текущий момент сайт сделан безопасно для коммерческого лендинга:

- в проекте используются **оригинальные шаблоны и код**;
- все изображения в `assets/images/` сейчас — это **внутренние SVG-заглушки**, а не чужие фото;
- внешние шрифты из Google не используются, чтобы снизить риски по лицензиям и приватности;
- ссылки на `Etsy` — это обычные внешние ссылки.

### Но перед запуском обязательно проверьте:
- что все реальные фотографии у вас **свои** или куплены с коммерческой лицензией;
- что тексты не скопированы с чужого сайта;
- что страницы `Impressum`, `Datenschutzerklärung`, `AGB`, `Widerrufsbelehrung` заполнены вашими реальными данными и проверены юридически.

> Юридические тексты в проекте сейчас являются **заготовками**, а не юридической консультацией.

## Локальный просмотр сайта (для разработчика)

Если сайт нужно открыть локально на компьютере:

```bash
bundle config set path 'vendor/bundle'
bundle install
bundle exec jekyll serve
```

После этого сайт будет доступен по адресу:
- `http://127.0.0.1:4000`
